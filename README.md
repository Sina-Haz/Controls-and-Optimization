# Controls and Optimization

Coursework repo for a Controls & Optimization class (nonlinear stability, LQR, trajectory tracking).

## Folders

- [`hw1/`](hw1/README.md) — stability of linear/nonlinear systems: delayed feedback, robust pole placement, exponential stability, gradient flow, 2D equilibrium analysis. Writeup in `Controls_HW_1.pdf`.
- [`hw2/`](hw2/README.md) — quadrotor trajectory tracking with time-varying LQR (linearization about a trajectory, differential Riccati equation, square-root/Cholesky factorization) plus grid-world value iteration. Writeup in `Controls_HW_2.pdf`.
- [`hw3/`](hw3/README.md) — cartpole energy-shaping swing-up (with a switch to LQR balancing near the upright equilibrium) plus a differentially-flat unicycle controller tracking a spline trajectory around random obstacles. Writeup in `Controls_HW_3.pdf`.
